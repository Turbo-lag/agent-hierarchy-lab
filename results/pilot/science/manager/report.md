# Solver verification report

The conservative centered solver passes both analytical manufactured-solution
studies on n = 16, 32, 64, 128. Both maximum nodal and discrete L2 errors decrease
approximately fourfold with each doubling of n. These are computed numerical
errors against analytical solutions, not experimental data or physical validation.

## Discretization and implementation

For h=1/n, write a_i=k((i-1/2)h) and c_i=k((i+1/2)h). Multiplying
the prescribed interior equation by h^2 gives

    -a_i u_(i-1) + (a_i+c_i) u_i - c_i u_(i+1) = h^2 f(x_i).

The unknowns are the n-1 interior nodal values. Move known Dirichlet values to
the right-hand side: add a_1*left in the first row and c_(n-1)*right in the last
row. When n=2 both contributions enter the same row. The returned lists include
the exact supplied boundaries after conversion to float. Positive face samples
make the interior matrix symmetric positive definite. Thomas forward elimination
and backward substitution use O(n) operations and O(n) storage; no dense matrix
is assembled.

The solver validates n as an int >=2 excluding bool, both functions as callable,
and all used scalar values as finite numbers.Real excluding bool. Coefficients
are evaluated only at face midpoints and must be positive there; sources only at
interior nodes. Noncallables and invalid values raise ValueError. Exceptions from
inside otherwise callable user functions propagate. No additional range restriction
is imposed. Supported accuracy covers coefficients [0.1,10], source/boundary
magnitude <=100, and n<=4096; finite behavior outside these ranges is unscored.

## Reproduction

Run locally from the supplied workspace using Python 3.11+ standard library:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest test_solution -v
PYTHONDONTWRITEBYTECODE=1 python3 verify.py
PYTHONDONTWRITEBYTECODE=1 ./verify.py
```

The verification command writes verification.json, overwriting that generated
artifact, and exits unsuccessfully if any verification check fails. It computes
all numbers afresh. The JSON uses no timestamps or unordered output and retains
full floating-point precision. Python 3.14.8 was used for the reported measurements;
last-bit differences across platforms are possible.

These root checks passed: one supplied smoke test, all 14 solution tests, and
the verification workflow. Direct executable invocation regenerated byte-identical
JSON. On this host a non-login shell resolves `python3` to the working Python
3.14.8; `python3.14` is also available. The login-shell `python3` launcher fails
because developer tools are unavailable. See `execution.md` for environment
and agent-organization evidence.

## Measured manufactured-solution errors

The maximum error includes every node. Discrete L2 is
sqrt(h * sum(interior_error^2)). Each order is log2(E_n/E_(2n)); the first grid
has no previous error and its JSON order is null. The residual is separately
computed as max interior abs(L_h(u_h)-f), with the operator including division
by h^2. It measures how closely the discrete linear equations are solved and
must not be interpreted as solution error.

## Interpretation and additional checks

For smooth k and u, the centered midpoint flux and its conservative difference
produce an O(h^2) truncation error. Uniform positivity provides stability for
this Dirichlet problem, so O(h^2) solution error is expected. The measured
orders are near two in both norms. Small departures are consistent with higher-order
terms and, for the variable-coefficient maximum error, grid sampling of the
continuous error maximum. There is no substantive
loss of second-order convergence on these grids. Algebraic residuals grow
slightly as h decreases because subtracting nearby computed solution values
and dividing by h^2 amplifies floating-point roundoff; they remain much smaller
than the solution errors.

Both manufactured cases enforce both boundaries exactly at every grid. A separate
n=64 case uses k=1+x, u=2x-0.75, f=-2, left=-0.75, right=1.25. Its max error
is 6.661338148e-16, discrete L2 error 3.420799627e-16, and max algebraic residual
1.818989404e-12. The affine profile is represented to roundoff with nonzero
boundary data and variable coefficients. All 39 invalid-input checks pass,
covering invalid n, noncallables, nonpositive coefficients, bool/nonreal values,
and NaN/infinities in both sampled functions and either boundary.

The solution tests also check the sole interior row at n=2, exact sampling
locations, late invalid samples, propagation of callable exceptions, Fraction
scalars, independent polynomial and exponential manufactured solutions, and
n=4096 with coefficients 0.1 and 10 and source/boundary magnitudes of 100.
The independent exponential study has maximum-error orders 1.99915 and
1.99883. Maximum-grid errors in the two coefficient-limit cases are 1.75e-10
and 7.59e-11. These checks passed with tolerances that allow floating-point
roundoff; they supplement the two required studies rather than replacing them.

The convergence check accepts orders strictly between 1.9 and 2.1; the
manufactured residual check uses 1e-8 and the affine max-error check uses 1e-11.
These are explicit numerical regression thresholds, not claims of exact arithmetic.
The study verifies the implementation on the stated smooth manufactured problems.
It does not establish accuracy for nonsmooth inputs, other discretizations, or
parameter regimes beyond the documented support. O(n) complexity follows from
the bounded number of linear passes; no timing benchmark is claimed.
